# ECHO DARK

真っ暗な世界で、**音の波紋だけが輪郭を照らす**ブラウザFPS(Unity WebGL)。

▶ 遊ぶ: https://tsubasakanke.github.io/echo-dark/

## 遊び方

- 「部屋を作る」→ 招待URLを友達に送る → 2〜8人そろったらリーダー(👑)がスタート
- 「ソロ練習」はボット相手の練習

| 操作 | |
|---|---|
| WASD | 移動(足元に小さな波) |
| Shift | 走る(波が大きくなる) |
| C | しゃがむ(無音) |
| 右クリック / F | 鈴(自分にだけ見える波) |
| 左クリック | 発砲(超広範囲に居場所がバレる) |
| H | 残光あり/なし の切替 |

## モード

- **個人戦**: 全員が敵。1ライフ、最後まで生き残った人がラウンド獲得。3ラウンド先取。
- **チーム戦**: 赤 vs 青。相手チームを全滅させたらラウンド獲得。3ラウンド先取。
- **鬼ごっこ**: 鬼だけが銃を持つ。逃げる側は隠れて逃げ切れ。ラウンドごとに鬼が交代。

残り30秒になると「心音」で全員の位置がバレる。

## しくみ

通信は公開MQTTブローカー(broker.emqx.io ほか)をリレーにしている。部屋の名前を知っている人なら誰でも入れるので、個人情報は名前に入れないでね。
