# ECHO DARK

真っ暗な世界で、**音の波紋だけが輪郭を照らす**ブラウザFPS(Unity WebGL)。

▶ 遊ぶ: https://tsubasakanke.github.io/echo-dark/

## 遊び方

- 「部屋を作る」→ 招待URLを友達に送る → 2〜8人そろったらリーダー(👑)がスタート
- 「ソロ練習」は NPC 3体との個人戦
- マップは試合ごとにランダム(高台・坂・階段つきの塔あり)
- 個人戦・チーム戦は NPC を入れられる(チーム戦は「人間は全員赤」で NPC チームと対戦も可)。人間+NPC で12人まで

| 操作 | |
|---|---|
| WASD | 移動(足元に小さな波) |
| Shift | 走る(波が大きくなる) |
| C | しゃがむ(無音) |
| Space | ジャンプ |
| 左クリック | 発砲(武器ごとに銃声の届く範囲が違う) |
| 右クリック / T | 狙う(ズーム。T は入/切) |
| R | リロード |
| F | 鈴(自分にだけ見える波) |
| Q / E | スキル |
| H | 残光あり/なし の切替 |
| V | 反響の残像あり/なし の切替(メニューでも設定できる) |

## アセンブル

試合前に武器1つ+スキル2つを選ぶ(ロビーでいつでも変えられる)。HP100、頭に当たると1.6倍。

- 武器: P90 / アサルトライフル / ショットガン / スナイパー(1発で倒せるが銃声が超大) / サプレッサー拳銃(銃声が極小)
- スキル: ハイジャンプ / スキャン(20m以内の敵が壁越しに光る) / ダッシュ(足音なし) / デコイ(ニセの銃声)
- チーム戦の味方は壁越しにいつも見える

## ステージ

高台 / 迷路 / 市街地 / 工場 / 平原 から選ぶ(ランダムも可)。中の配置は毎回ランダム。

## 音だけで戦う

- 照準のまわりに、聞こえた音の方向が色つきの弧で出る(銃声=赤、足音=青、心音=紫)
- 波が敵を通りすぎると、その瞬間の姿が「残像」として残る
- 画面下の「あなたの音」メーターで、自分がどれだけ音を出しているか分かる

## モード

- **個人戦**: 全員が敵。1ライフ、最後まで生き残った人がラウンド獲得。3ラウンド先取。
- **チーム戦**: 赤 vs 青。相手チームを全滅させたらラウンド獲得。3ラウンド先取。
- **鬼ごっこ**: 鬼だけが銃を持つ。逃げる側は隠れて逃げ切れ。ラウンドごとに鬼が交代。

残り30秒になると「心音」で全員の位置がバレる。
